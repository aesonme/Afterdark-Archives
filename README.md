# Afterdark Archives

A mature, colorful, macabre personal website designed for GitHub Pages.

## Customize
- Edit `index.html` to replace sample journal entries, favorites, and contact email.
- Edit colors and layout in `style.css`.
- Edit interactions in `script.js`.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
5. Save and open the generated GitHub Pages URL.
